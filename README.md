# Fenced Code Blocks Tools

Fork of [Markdown Enhanced Code Block](https://github.com/kiran-machhewar/Markdown-Enhanced-Code-Block)

Icons above fenced markdown code with various functions

## New / Changed Features

### Tools

```
    ``` [syntax id]
        Show tools above fenced code block
    ```
```

📎 Copy

📋 Paste

🔦 Select

🐀 Cursor

🗑️ Delete

🔜 Indent

🔙 Outdent

🪹 Nest

🐑 Clone

✂️ Cut

❌ Remove

🧮 Counter

💲 Terminal

* Lines Total

### Ignore

```
    ``` (optional) !
        Put a `!` at end, to not use this extension
    ```
```
